# ABM en C y Python

En este repositorio vas a encontrar dos sistemas de ABM (Alta, Baja y Modificación) uno escrito en **C** y el otro en **Python**.

---

## 📁 Estructura

* `c/` -> Código fuente y ejecución de la versión en C.
* `python/` -> Código fuente y ejecución de la versión en Python.

---

## Para probarlos

### Versión en C
```bash
gcc main.c -o abm
./abm
```

### Versión en Python
```bash
python main.py
```
